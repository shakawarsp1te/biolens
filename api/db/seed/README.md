# Oncology seed data

`oncology_seed.sql` is generated by `generate_oncology_seed.py` — edit the
Python file, not the SQL directly, then re-run:

```
python3 generate_oncology_seed.py
```

## What's in it

10 companies, 16 drugs, 15 targets, 19 trials, 23 indications. All real,
individually web-search-verified as of **August 19, 2026** — not the
checklist's round 10/20/10/20, because every row here is a real, currently
active company/program and none were invented to pad the count. See the
generator's docstring and each row's `sources` entry (a real URL) for
citations.

Every company was checked for: still independent, ticker current, program
active, not acquired. One casualty of that check during research: Mersana
Therapeutics was going to be seed company #7 until search turned up that Day
One Biopharmaceuticals completed acquiring it in January 2026 (delisted from
Nasdaq) — excluded. Janux's second program, JANX008, was similarly dropped
after search showed Janux discontinued it in April 2026.

**No `trial_results` (statistics) are seeded.** Extracting and correctly
framing a trial statistic (ORR with denominator, HR with plain-language
framing, endpoint role, etc.) is Phase 6's job — hand-typing numbers here
would be exactly the kind of fabrication the product rules forbid, just
committed a phase early instead of at inference time.

## Before running this

`db/migrations/0001_init_schema.sql` must be run first (it creates the
tables this seeds into). Both files are written for the Supabase SQL editor,
in order: run the migration, then this seed file.

Neither file has been executed against a live database yet — no Supabase
project existed at the time they were written. They were checked for
paren/quote balance and reviewed by hand, but need a real execution pass the
first time a Supabase project is available.
